## Patch instructions  🩹

1. Visit [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/), or use an offline xdelta patcher.
2. Obtain a disc dump matching [these hashes](http://redump.org/disc/59761/). 
3. Select `Rakugaki Showtime (Japan).bin` as ROM file.
4. Download the [latest xdelta patch in this folder](https://raw.githubusercontent.com/eadmaster/ezrominject/refs/heads/main/examples/Rakugaki%20Showtime%20PS1/Rakugaki%20Showtime%20(English).bin.xdelta), and use it as the Patch file.
   - Note: This is a **rolling release**: check frequently for the latest fixes/improvements.
5. Click "Apply patch" and save in the same folder as `"Rakugaki Showtime (English).bin`
6. Download and use the cue sheet in this folder to play the game
